Setup instructions

1. Create a GitHub OAuth App at github.com/settings/developers .

2. Set the Authorization callback URL to this page's URL.

3. Enable "Public client" (Allow device and PKCE flows) on the OAuth App settings.

4. Copy your Client ID into the CLIENT_ID constant at the top of this file's script.
